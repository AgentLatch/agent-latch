# Detection rules and OWASP mapping notes

AgentLatch v0.1.0 contains a few deterministic source-pattern and agent-manifest checks. A hit means “review this code,” not “this code is exploitable.” A clean result means only that these patterns were not found in the scanned files.

| Rule | Detection | OWASP Agentic Top 10 mapping | Limitations |
|---|---|---|---|
| AGENTLATCH-PY001 | Python direct calls to `eval()` or `exec()` | ASI05 Unexpected Code Execution; ASI02 Tool Misuse & Exploitation | Does not establish whether the argument is attacker-controlled; misses indirect invocation and aliases. |
| AGENTLATCH-PY002 | `subprocess.*(..., shell=True)` | ASI05 Unexpected Code Execution; ASI02 Tool Misuse & Exploitation | Does not prove command injection; misses wrappers and aliases. |
| AGENTLATCH-PY003 | A call with literal `verify=False` | ASI02 Tool Misuse & Exploitation | Heuristic; does not resolve the called library or runtime context. |
| AGENTLATCH-AG001 | `Agent(..., allow_delegation=True)` | ASI02 Tool Misuse & Exploitation | CrewAI-specific review hint, not automatically a vulnerability. |
| AGENTLATCH-SEC001 | Credential-like assignment to a quoted literal | ASI03 Identity & Privilege Abuse; ASI04 Agentic Supply Chain Vulnerabilities | Heuristic; may miss encoded/dynamic secrets and may report harmless test values. Values are redacted. |
| AGENTLATCH-AG002 | LangChain `create_pandas_dataframe_agent(...)` factory call | ASI05 Unexpected Code Execution; ASI02 Tool Misuse & Exploitation | Flags the capability for review even when guarded by a runtime flag; it does not prove that the dangerous option is enabled in every execution. |
| AGENTLATCH-AG003 | Output of a known web-search tool, web loader, or HTTP client (`requests`, `httpx`, `urlopen`) reaching `HumanMessage`/`SystemMessage`/`ChatMessage` content or a `{"role": ..., "content": ...}` message, traced through assignments, loops, returns, call arguments, and LangGraph-style state keys | ASI01 Agent Goal Hijack | Single-file, name-based tracking: misses aliases, attributes, cross-module flow, and unlisted tools; may over-report when the same key name is reused. Content fenced in tag-like delimiters (`<page>...</page>`) or labelled untrusted is treated as mitigated. Low confidence. |
| AGENTLATCH-DEP001 | A known vulnerability advisory for a requirement | ASI04 Agentic Supply Chain Vulnerabilities | Requires `--dependencies`; only scans `requirements*.txt`; advisory coverage depends on the configured vulnerability service and package/version data. `pip-audit` does not provide normalized severity here, so severity is reported as `unknown`. Duplicate package/version/advisory records are collapsed. |
| AGENTLATCH-MAN001 | Manifest tool with a high-risk capability (shell, code execution, filesystem/database write, payments, email send, admin) and no `requires_approval`, `human_in_the_loop`, or `require_confirmation` | ASI02 Tool Misuse & Exploitation; ASI05 (code execution) or ASI03 (other capabilities) | Only sees what the manifest declares; capability names are matched against a fixed list. |
| AGENTLATCH-MAN002 | Manifest tool with wildcard permissions (`*`, `all`, `any`, or `scope:*`) | ASI02 Tool Misuse & Exploitation; ASI03 Identity & Privilege Abuse | Declared scope only; does not check what credentials the tool actually holds. |
| AGENTLATCH-MAN003 | Manifest tool with an `endpoint`/`url`/`base_url`/`server` and `auth` missing or set to `none` | ASI03 Identity & Privilege Abuse; ASI02 Tool Misuse & Exploitation | Missing `auth` is reported with low confidence; auth may be handled elsewhere. |
| AGENTLATCH-PRM001 | Instruction-override phrases (for example “ignore all previous instructions”) in manifest prompts or referenced prompt templates | ASI01 Agent Goal Hijack | Fixed English signatures; paraphrased, encoded, or non-English injections are missed. Security-training text can match. |
| AGENTLATCH-PRM002 | A user-input-like placeholder (`{user_input}`, `{{ query }}`, `${message}`) inside a system prompt | ASI01 Agent Goal Hijack | Name-based heuristic; reports low confidence. |
| AGENTLATCH-MAN000 | A prompt file referenced by the manifest could not be read | — | Informational coverage note; does not affect `--fail-on`. |

OWASP category titles and mapping are informational references to the [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/). AgentLatch is independent and is not endorsed, approved, or certified by OWASP. Review the OWASP source for current definitions and version changes.
