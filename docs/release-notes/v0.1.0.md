First public release of AgentLatch, a local-first security scanner for AI-agent projects. It finds risky patterns in agent code, tool definitions, and prompts before you run or deploy them, and maps findings to the OWASP Top 10 for Agentic Applications.

> **Early proof of concept.** Checks are static heuristics. A clean scan means only that the enabled checks found nothing, not that an agent is secure.

## Highlights

- **Agent manifest audit:** `agent-latch scan --config agent-manifest.yaml` checks declared tools for high-risk capabilities without human approval, wildcard permissions, and remote endpoints without authentication.
- **Prompt checks:** flags prompt-injection phrases in prompt templates and user input interpolated into system prompts.
- **Indirect prompt injection detection:** traces web-search, web-loader, and HTTP output into LLM messages across functions and LangGraph state.
- **GitHub Action:** scan on every push or pull request, upload SARIF to code scanning, get a findings table in the job summary, and fail on a chosen severity.
- **pre-commit hook:** block commits that introduce high-severity findings.
- **Known findings and false positives:** record accepted findings in `.agent-latch-ignore`, or with inline `# agent-latch: ignore[RULE]` comments.

## Quick start

```sh
git clone https://github.com/AgentLatch/agent-latch.git
cd agent-latch
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e .
agent-latch scan /path/to/my-agent
```

GitHub Actions:

```yaml
- uses: AgentLatch/agent-latch@v0.1.0
  with:
    fail-on: high
```

## Checks in this release

| Area | Rules |
|---|---|
| Python source | `PY001` eval/exec, `PY002` shell=True, `PY003` verify=False |
| Agent frameworks | `AG001` CrewAI delegation, `AG002` LangChain dataframe agent code execution, `AG003` untrusted web/tool output in prompts |
| Agent manifests | `MAN001` high-risk tool without approval, `MAN002` wildcard permissions, `MAN003` remote tool without auth |
| Prompts | `PRM001` prompt-injection phrases, `PRM002` user input in system prompt |
| Secrets | `SEC001` hardcoded credentials (values redacted) |
| Dependencies | `DEP001` known advisories via pip-audit (opt-in, `--dependencies`) |

Reports are available as a terminal table, plain text, JSON, or SARIF.

## Requirements and limits

- Python 3.11 or newer. The GitHub Action runs on Linux and macOS runners.
- Source scanning is local; nothing is uploaded. The opt-in dependency audit sends package names and versions to PyPI's advisory service.
- Uploading to code scanning on private repositories requires GitHub Advanced Security.
